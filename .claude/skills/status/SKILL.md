# Status – the running overview

`STATUS.md` in the repo root is the one page where Loris always sees what's happening on Instagram.
It is generated by `automation/status.py` and rewritten by `.github/workflows/status.yml` after **every push**, after **every run**
of post/approval/stats/token/music and every morning. Its log comes from the git history – every commit (autopilot and manual)
shows up automatically, including the changes to `automation/plan.json`.
The same script writes `STATUS.html` (visual page, `automation/status_html.py`); the status workflow publishes it on
GitHub Pages: https://maehrsteuern.github.io/maehrtax---instagram/ – when you add a section to STATUS.md, add it there too.

## At the start of every session
1. `git pull` on `main` (or the working branch), then `python3 automation/status.py`.
2. Read `STATUS.md` – especially **Needs you**, **Next 7 days** and **Automation** (red entries = errors).
3. Tell Loris briefly **in German** what goes live next and what's open, before doing anything else.

## After every change
- Commit message in English, understandable on its own in the log
  (e.g. "Plan: move Reel 4,000 rows to Tue 12:30 PM ET (holiday)"). The log only shows the message + plan changes.
- If what's being worked on changes or something was decided: update `automation/status_notes.md`
  (short bullets, delete outdated ones). It appears at the top of STATUS.md under "In progress".
- Run `python3 automation/status.py` and commit `STATUS.md` + `STATUS.html` too. (The workflow does it after the push anyway.)
- Never edit `STATUS.md`/`STATUS.html` by hand – they get overwritten. If something is missing there, extend `automation/status.py`.

## Status values in plan.json
`draft` → approval issue, "go" → `approved` → autopilot posts → `published` (with permalink).
`manual` = Loris posts in the app (sticker stories, trending sounds) · `waiting_<reason>` = blocked (e.g. `waiting_voice_note`, `waiting_concept`) · `error` = posting failed · `cancelled` = dropped.
All plan times are US Eastern (America/New_York); Loris is in Berlin (ET + 6 h, + 5 h during the DST gap weeks).
