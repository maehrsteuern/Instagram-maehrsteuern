# Formel für Demo-Reels (10–12 s)

Abgeleitet aus den Insights vom 30.09.2026: Beim ersten Reel haben 68 % gleich weitergewischt, im Schnitt wurde es 7 s angesehen, 3 Mal geteilt.
Vorlage zum Kopieren: `vorlagen/system/schnitt/p01_reel_ampel_musik.json`.

| Zeit | Baustein | Regel |
|---|---|---|
| 0–1,3 s | **Schmerz** | Echtes Chaos-Bild (Excel, Fehler) + Haken, der einen bekannten Schmerz trifft, keine Feststellung. Text ab dem ersten Bild (`"sofort": true`). |
| 1,3–3,4 s | **Schnitt + offener Punkt** | Harter Schnitt aufs Tool. Unterzeile verspricht, was noch kommt („Achte auf die Ampel.“). |
| 3,4–5,4 s | **1 Nutzen** | Eine Leiste, max. 2 s. Lieber eine Aussage weniger. |
| 5,4–8,6 s | **Höhepunkt** | Sichtbarer Wechsel (Rot → Gelb → Grün, Zahl springt, Fehler verschwindet) als große Nahaufnahme. Vorlage `ampel.html`. |
| 8,6–11 s | **Aufruf auf dem Bild** | „TOOL“ per DM als Leiste über dem Tool, **kein Abspann-Standbild**. So läuft das Reel nahtlos von vorn. |

**Bildunterschrift:** Haken wiederholen → 2 Sätze Nutzen → Frage für Kommentare → **Aufruf zum Teilen** („Schick das dem Kollegen, der …“) → „TOOL“ per DM.

**Nach 48 h prüfen** (`automatik/statistik/`): Überspringrate unter 60 %? Durchschnittliche Sehdauer über 60 % der Länge? Geteilt ≥ Gespeichert?
