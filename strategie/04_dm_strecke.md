# 4 · DM-Strecke „TOOL“ → Demo + Erstgespräch

## Ablauf auf einen Blick
```
„TOOL“ per DM oder Kommentar
   │
   ▼
① Begrüßung + Frage: Wo arbeitest du?  (1 Steuerabteilung · 2 Kanzlei · 3 Selbstständig/KMU · 4 Studium/Ausbildung)
   │
   ├── 1 / 2 / 3 ──► ② Frage: Welche Excel-Liste nervt dich am meisten?
   │                    │
   │                    ▼
   │                 ③ Demo-Video + Terminlink (20 Min.)
   │                    │
   │                    ├── Termin gebucht ──► ⑤ Danke + Vorbereitung
   │                    └── nach 2 Tagen nichts ──► ④ eine Erinnerung, dann Ruhe
   │
   └── 4 ──────────► ③b Demo-Video + Hinweis auf Wissen-Highlight, freundlich, kein Termin-Druck
```

## Die Nachrichten (zum Kopieren)

**① Begrüßung – sofort**
```
Hey, danke dir! 🙌
Kurz vorab, damit ich dir das Passende zeige: Wo arbeitest du?
1 – Steuerabteilung
2 – Kanzlei
3 – Selbstständig / KMU
4 – Studium / Ausbildung
Antwort einfach mit der Zahl 😊
```

**② Bedarf (bei 1–3)**
```
Top! Welche Excel-Liste oder Berechnung kostet dich gerade am meisten Zeit?
Ein Stichwort reicht, z. B. „Steuerrückstellung“, „Gewerbesteuer“, „Abstimmung“.
```

**③ Demo + Termin (bei 1–3)**
```
Danke, das kenne ich gut. Hier ist die Demo (Beispieldaten, 2 Min.): [LINK DEMO-VIDEO]

Wenn du sehen willst, wie das für „[Stichwort]“ aussehen könnte:
20 Minuten, kostenlos und unverbindlich 👉 https://app.reclaim.ai/m/maehrsteuern/demo

Wichtig: Bitte schick mir keine echten Mandanten- oder Firmendaten per DM.
```

**③b Studium / Ausbildung**
```
Cool, dann bist du hier richtig! Hier die Demo zum Anschauen: [LINK DEMO-VIDEO]
Zum Lernen: Schau ins Highlight „Wissen 📚“ – da sammle ich die Rechenbeispiele.
Und wenn du Fragen hast: einfach schreiben ✌️
```

**④ Erinnerung – nur einmal, nach 2 Tagen**
```
Kurze Erinnerung, falls es untergegangen ist: Der Termin für die Demo ist hier 👉 https://app.reclaim.ai/m/maehrsteuern/demo
Wenn's gerade nicht passt, ist das völlig okay – die Einladung bleibt stehen.
```

**⑤ Nach der Buchung**
```
Super, freu mich! 🙌 Damit wir die 20 Minuten gut nutzen:
Überleg dir kurz, welcher Ablauf heute am längsten dauert. Mehr Vorbereitung brauchst du nicht.
```

**Nach dem Gespräch (1–2 Tage später)**
```
Danke nochmal für das Gespräch! Darf ich deine Rückmeldung anonym im Highlight „Feedbacks“ zeigen?
```

## Technik – in zwei Stufen
**Stufe 1 (jetzt, kostenlos): Schnellantworten**
Instagram → Einstellungen → *Business-Tools* bzw. *Creator-Tools* → **Schnellantworten**. Pro Nachricht ein Kürzel anlegen:
`/tool1` (①), `/tool2` (②), `/tool3` (③), `/tool3b` (③b), `/tool4` (④), `/tool5` (⑤).
Im Chat Kürzel tippen → Text wird eingefügt. Bei unter ~10 DMs pro Woche reicht das völlig und wirkt persönlicher.

**Stufe 2 (ab ca. 10 DMs pro Woche): Automatisierung**
Mit einem Instagram-Automatisierungsdienst wie ManyChat (kostenloser Einstieg) Stichwort „TOOL“ als Auslöser einrichten – für DMs **und** Kommentare. Kommentar-Auslöser bringt zusätzlich Reichweite, weil jeder Kommentar den Beitrag pusht. Dann in Reels schreiben: „Kommentiere TOOL“.
